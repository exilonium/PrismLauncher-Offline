# Prism Launcher (Offline)

Prism Launcher (Offline) is a fork of [Prism Launcher](https://github.com/PrismLauncher/PrismLauncher) but with Microsoft login features not enforced.
This repo will be up to date with Prism Launcher's latest release and will work just fine.

## Installation

see the release page for the install or you can build it yourself see building section.

## Building

see the [building guide](BUILDING.md) for instructions on how to build the project.
